# Privacy

Barista does not collect analytics, advertising identifiers, usage histories,
or personal information. There is no account, advertising, or subscription.

## App preferences

Keep-awake settings, durations, startup choices, and menu bar preferences stay
on your Mac. They are not sent to us. Uninstalling the app does not automatically
remove its saved preferences.

## App Store edition

The sandboxed App Store edition communicates with its own local backend over
an authenticated loopback connection. It does not send app usage or preferences
to an external service. Apple manages distribution and updates through the Mac
App Store under [Apple’s privacy policy](https://www.apple.com/legal/privacy/).

## GitHub edition

Update checks contact GitHub to read Barista’s public release information and
download a newer signed app. GitHub receives normal network information such
as your IP address. Barista does not add preference data or a tracking identifier
to those requests. See [GitHub’s privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Optional icon grouping uses Accessibility and a private macOS API locally. It
does not record or transmit your menu bar contents. Grouping is available only
in the GitHub edition.

## Website and external links

The marketing site and documentation do not use analytics or advertising
trackers. The theme selector stores your preference in your browser. Hosting
providers may process ordinary request information to serve and protect the
site. Links to GitHub and Apple open those services, whose own privacy policies
apply.
