# Barista documentation

Keep your Mac awake and hide a chosen group of menu bar icons. Barista is a
free, MIT-licensed macOS utility built with stx and Craft.

The packaged app requires **Apple Silicon and macOS 15 or newer**. Icon grouping
is available in the direct build.

- [Get started](./intro.md): download, install and use the cup.
- [Keep awake](./caffeinate.md): durations, shortcuts and sleep behavior.
- [Configuration](./config.md): login startup, grouping and native API limits.
- [Updates](./updates.md): check, download and install verified releases.
- [Releasing](./releasing.md): signing, encrypted credentials and verification.
- [Website development](./site.md): Stacks sources, assets, builds and preview.
- [Website deployment](./deployment.md): publish to the shared Stacks server.

Download the signed, notarized DMG from
[GitHub Releases](https://github.com/stacksjs/barista/releases/latest).
